Desenvolvido por Davi Leal

Sobre o Projeto

O davIA Physics Lab 2.0 é um software educacional desenvolvido em Python, com o objetivo de proporcionar um ambiente virtual e interativo para o estudo de fenômenos físicos.

A plataforma busca integrar tecnologia, experimentação e ensino de Física, permitindo que estudantes e professores explorem conceitos científicos por meio de simulações computacionais.

Objetivos

- Facilitar a compreensão de fenômenos físicos.
- Promover o ensino experimental por meio de simulações.
- Desenvolver habilidades de investigação científica.
- Integrar programação e ensino de Física.
- Oferecer ferramentas interativas para professores e estudantes.

Experimentos

1. Pêndulo Simples

Simulação do movimento de um pêndulo, permitindo explorar conceitos de período, frequência, comprimento e gravidade.

2. Queda Livre

Módulo em desenvolvimento, destinado ao estudo do movimento vertical dos corpos sob ação da gravidade.

Funcionalidades planejadas:

- Controle da altura inicial.
- Ajuste da aceleração gravitacional.
- Cálculo do tempo de queda.
- Cálculo da velocidade.
- Animação do movimento.
- Gráficos de posição em função do tempo.
- Exportação de dados em CSV.

Tecnologias Utilizadas

- Python
- Tkinter
- Matplotlib
- NumPy
- PyInstaller

Plataforma

Sistema operacional: Windows.

Execução

Para executar o projeto pelo Python:

python DAVIA_Physics_Lab.py
